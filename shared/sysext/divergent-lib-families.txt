# Shared-library families that at least one desktop product has shipped
# from a suite other than the base release (trixie-backports/forky while the
# base was trixie), so a sysext delta copy would shadow-DOWNGRADE the
# product's version for the whole merged /usr (issue #781; root-caused live
# 2026-08-25 on a since-retired Hyprland desktop product that pinned much
# of its GUI stack from trixie-backports). Since the 2026-09 forky move no
# product pins a second suite, so every family below is defence in depth;
# the list is kept because the shadowing mechanism is unchanged.
#
# Format: one shell glob per line, matched against paths RELATIVE to the
# delta's /usr (e.g. lib/x86_64-linux-gnu/libxkbcommon.so.0.0.0).
# Comments and blank lines ignored.
#
# A match in a gui-base-built sysext delta fails the build
# (shared/sysext/finalize/sysext-no-divergent-libs.sh): it means either
# gui-base lost the package or apt upgraded the lib INTO the delta because
# the app now needs a newer version than gui-base carries -- both need
# re-triage, never normalization.

# xkbcommon (the original case: trixie-backports 1.13 vs trixie 1.7 on the
# retired product. Kept as defence in depth -- gui-base carries
# libxkbcommon0, so a match here means gui-base lost it or apt upgraded the
# lib into a delta)
lib/*/libxkbcommon*.so*
lib/*/libxkbregistry*.so*

# pipewire family (trixie-backports 1.4.9 vs trixie 1.4.2 on the retired
# product; same defence-in-depth reasoning as xkbcommon)
lib/*/libpipewire*.so*
lib/*/pipewire-0.3/*
lib/*/spa-0.2/*
lib/*/libwireplumber*.so*

# mesa userspace -- was LIVE on the trixie base: snowfield pinned mesa from
# trixie-backports through shared/kernel/surface/mkosi.conf while snow
# tracked trixie; both now take forky's mesa.
# Includes the mesa-vulkan-drivers ICDs and layers -- chatgpt's deb
# hard-depends on that package, which is why gui-base and
# shared/packages/snow both carry it.
lib/*/libgbm.so*
lib/*/libgallium*.so*
lib/*/libEGL_mesa*.so*
lib/*/libGLX_mesa*.so*
lib/*/dri/*
lib/*/gbm/*
lib/*/libvulkan_*.so*
lib/*/libVkLayer_*.so*

# alsa (trixie-backports 1.2.16 vs trixie 1.2.14 on the retired product;
# same defence-in-depth reasoning as xkbcommon)
lib/*/libasound.so*

# systemd libraries (the secure products shipped the forky systemd family
# on a trixie base; theoretical member of the class -- no sysext ships
# these today)
lib/*/libsystemd.so*
lib/*/libudev.so*
